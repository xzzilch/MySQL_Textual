# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Once this project is hosted, use GitHub's **Report a vulnerability** option in the repository's Security tab so maintainers can coordinate a private response. Repository administrators should enable private vulnerability reporting in the repository settings.

Do not include real database credentials, production data, or connection dumps in reports. Provide a minimal reproduction with secrets removed.

## Supported versions

Security fixes target the latest released version. Until the first release, use the latest source revision and keep Python and MySQL Connector/Python updated.
